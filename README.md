One cat joke, one line, under 200 characters. The program writes the joke to `entry.txt`.

> My cat charges me rent now. I pay in treats, and she already evicted the dog for excessive loyalty.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
